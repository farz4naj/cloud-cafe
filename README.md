
# ☕ Cloud Cafe

Cloud Cafe is a simple and modern landing page for a cozy coffee shop in Kabul, Afghanistan.

The website is designed to give visitors a warm first impression and introduce the café, its services, menu, and contact information.

### ✨ Features
- Clean and modern design
- Responsive layout for mobile and desktop
- About and services sections
- Featured menu items
- Interactive navigation using JavaScript
- Contact form with basic validation

### 🛠️ Built With
- HTML
- CSS
- JavaScript

### 📁 Project Files
- `index.html` – Website structure
- `style.css` – Design and styling
- `main.js` – Interactive features
